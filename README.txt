GROWTH HIRE PARTNERS WEBSITE
============================

PROJECT CONTENTS
- index.html        Home page
- about.html        About Us page
- services.html     Our Services page
- contact.html      Contact Us page
- css/style.css     Website styling and responsive layout
- js/main.js        Mobile menu, current year, demo form validation and WhatsApp link

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension (optional but recommended).
4. Right-click index.html and select "Open with Live Server".
   Or open index.html directly in a browser.

IMPORTANT BEFORE PUBLISHING
1. Replace placeholder email, phone number and office address in all HTML files.
2. Replace 91XXXXXXXXXX in js/main.js with the official WhatsApp number (digits only, including country code).
3. The employer and candidate forms are FRONT-END DEMOS only. They do not send email or store submissions.
4. Connect forms to a secure backend or trusted form service before collecting real candidate information.
5. Configure secure resume upload, access controls, privacy notice, retention policy and consent before accepting CVs.
6. Confirm that all listed recruitment services and industries are actually offered by the company.
7. Add the approved company logo and real images if supplied by the company.
8. Add real social media links and legal/privacy pages as required.

TECHNOLOGY
HTML5, CSS3 and vanilla JavaScript.
Google Fonts are loaded online; a fallback font is included.
